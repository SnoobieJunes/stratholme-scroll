# Stratholme Supply Company — Scroll

Live: https://snoobiejunes.github.io/stratholme-scroll/

The page uses whatever window you give it. Type shrinks, and the story runs in columns, until the whole tale fits on that one screen. Widen the window if you want larger type.

Friar Baggins is loaded as the sample. **New associate** clears the scroll.

The seal and the note at the foot are the Company. The tale is not rewritten.

## Use

1. Open the page.
2. Paste the story. A blank line starts a new paragraph. A line that is only `**Like This**` or `# Like This` becomes a heading. `*asterisks*` make italics.
3. **Save scroll.** Drag the image into Discord. The channel shows the top — the name sits under the seal. Open the image to read the rest.

If the browser only offers a print dialog, use **Print / save PDF**.

To run a copy without this site, open `index.html` in a browser.
